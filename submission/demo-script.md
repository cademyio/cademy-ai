# Demo video script

About 3 minutes. Record in ChatGPT (OpenAI requires a video URL) and reuse for Claude if asked. Use the `zoomtester` review account. Keep the Cademy app open in a second tab to show changes landing.

| Time | On screen | Say |
| --- | --- | --- |
| 0:00 | Cademy dashboard | "Cademy runs bookings and training admin for course providers. Here's what it looks like from ChatGPT." |
| 0:10 | Install Cademy from the plugin directory, click Connect, Cademy consent page, Allow | "You connect with your own Cademy login. The assistant can only see and do what your role allows." |
| 0:30 | Prompt: "Which courses are running between 1 and 12 December, and does every date have a trainer?" | "Questions are answered from live Cademy data." Point at the date with no trainer. |
| 0:55 | Prompt: "Run the Project Planning in 90 Minutes course day on 18 December: everyone attended except Noah, issue certificates without emailing anyone, then ask attendees for feedback." | "The course-day skill knows the order a trainer works in." |
| 1:15 | The preview summary, then type "Yes" | "Nothing changes until you confirm. One preview, one question." |
| 1:35 | Cademy tab: registrations attended, Noah absent, certificates issued | "Changes land in Cademy, with an Activity Log entry for each." |
| 1:50 | Prompt: "Which December bookings still owe money? Draft a reminder." | "It lists what's owed in your currency and drafts a reminder, but sends nothing until you ask." |
| 2:15 | Prompt: "Import these contacts and tell me about duplicates first." with a pasted CSV | "Imports are checked row by row first: duplicates and errors before anything is written." |
| 2:40 | Prompt: "What's the weather tomorrow?" | "Unrelated questions don't touch your Cademy account." |
| 2:50 | Cademy Settings › Connected AI Apps | "You can see and disconnect every AI app from Settings in Cademy." |

Before recording: record before 18 December, while the sample dates are still ahead, hide the browser bookmarks bar, and use a clean chat.
